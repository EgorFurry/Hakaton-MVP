# Как работать с GitHub — туториал для команды OpenSense

## 1. Установка Git
Скачай: https://git-scm.com/download/win

При установке везде жми Next.  
⚠️ На первом экране обязательно поставь галочку **Add Python to PATH** (для Git это **Add Git to PATH**).

---

## 2. Настройка (один раз на компьютере)

Открой **Git Bash** (он установится вместе с Git) и введи:

```bash
git config --global user.name "ТвоёИмя"
git config --global user.email "твоя@почта.com"
```

Это нужно чтобы Git знал кто делает изменения. Используй почту от GitHub аккаунта.

---

## 3. Клонировать репозиторий (один раз)

```bash
git clone https://github.com/EgorFurry/Hakaton-MVP.git  #Это скачает проект на твой компьютер.
cd Hakaton-MVP  #для перехода на файл 
```
---

## 4. Переключиться на свою ветку

| Кто      | Ветка      |
|----------|------------|
| Бекболат | `frontend` |
| Тимур    | `backend`  |

```bash
git checkout frontend
```

---

## 5. Каждый день перед работой — подтянуть изменения

```bash
git pull origin frontend
```

⚠️ Делай это ПЕРЕД началом работы — иначе будут конфликты.

---

## 6. Сохранить свои изменения

Три команды по порядку:

```bash
git add . (. - это все файлы если нужно конкретный указываете его)
git commit -m "Что ты сделал — напиши понятно \ а еще пиздеть буду если на кирилице напишите"
git push origin frontend #это уже сам пуш на ветку 
```

**Примеры хороших сообщений коммитов:**
- `Add navigation menu to index.html`
- `Fix button color on mobile`
- `Update contacts page layout`

**Плохие сообщения:**
- `fix`
- `changes`
- `aaaaaa`

---

## 7. Правила команды

- ❌ Никогда не пушь в `main` напрямую
- ✅ Всегда работай в своей ветке
- ✅ Пиши понятные сообщения коммитов
- ✅ Перед работой всегда делай `git pull`

---

## 8. Частые ошибки и решения

### Ошибка: "rejected, fetch first"

Это значит: кто-то из команды запушил изменения пока ты работал.
Git не даёт тебе пушить пока ты не подтянешь их изменения.

Решение — две команды по порядку:

Шаг 1 — скачай чужие изменения:
git pull origin frontend --no-edit

Шаг 2 — теперь пушь свои:
git push origin frontend

Замени "frontend" на название своей ветки если она другая.

### Ошибка: "not a git command"
Проверь написание команды — скорее всего опечатка. Например `git comit` вместо `git commit`.

### Ошибка: "Please tell me who you are"
Ты не настроил имя и почту. Вернись к шагу 2.

## 10. Полезные команды

| Команда                  | Что делает                        |
|--------------------------|-----------                        |
| `git status`             | Показывает что изменилось         |
| `git log`                | История коммитов                  |
| `git branch`             | Список веток (звёздочка = текущая)|
| `git checkout имя_ветки` | Переключиться на ветку            |
| `git diff`               | Посмотреть изменения в файлах     |
